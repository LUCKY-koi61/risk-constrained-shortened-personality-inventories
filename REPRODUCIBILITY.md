# Reproducibility notes

## Environment

The audited reruns used Python 3.10+ and the package versions pinned in
`requirements.txt`:

```text
numpy==2.2.6
pandas==2.2.3
scipy==1.13.1
matplotlib==3.10.8
```

## Data inputs

P0 and P4 do not redistribute respondent-level data. Follow
[`DATA_SOURCES.md`](DATA_SOURCES.md) to download the four public source
archives. The expected extracted layout is listed in the README. The P1–P3
scripts are self-contained simulations.

## Expected outputs

Each script writes a JSON result and, where applicable, a CSV summary under
`results/`. These tracked result files are frozen, non-identifying outputs.
For P0–P4, the audited reruns regenerated byte-identical JSON/CSV outputs from
the source code and input data.

## Scope

The repository supports computational reproduction of full-form-referenced
screening analyses and known-truth simulations. It does not provide a clinical
screening instrument, clinical outcomes, or participant-level source data.
