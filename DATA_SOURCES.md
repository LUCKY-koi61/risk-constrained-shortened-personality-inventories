# Data sources

The analysis uses the publicly available, anonymous Open-Source Psychometrics Project data:

- Raw-data archive: https://openpsychometrics.org/_rawdata/
- Local source archives used for this study: `HEXACO.zip`, `BIG5.zip`, `NPI.zip`, and `SD3.zip`.

Raw respondent data are not duplicated in this archive. Download the source archives directly from the provider and preserve their codebooks.
